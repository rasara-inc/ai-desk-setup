# VS Code를 업무 책상으로 쓰기

Finder에서 `AI Desk.code-workspace`를 더블 클릭하거나 VS Code에서 AI Desk 폴더를 여세요.
왼쪽은 파일 목록, 가운데는 문서, Codex는 AI 대화입니다.
설치 시 줄 번호·미니맵·Git 표시를 줄이고 자동 저장을 켭니다.
파일 목록과 Codex까지 숨기지는 않습니다.

## 자주 쓰는 Mac 단축키

| 동작 | 단축키 |
| --- | --- |
| 저장 | ⌘S |
| 파일 이름으로 찾기 | ⌘P |
| 기능 이름으로 실행(명령 팔레트) | ⇧⌘P |
| 지금 파일에서 찾기 | ⌘F |
| 폴더 전체 내용 검색 | ⇧⌘F |
| 왼쪽 파일 목록 숨기기/보기 | ⌘B |
| Markdown 미리보기 | ⇧⌘V |
| Markdown을 옆에서 미리보기 | ⌘K를 누른 뒤 V |
| 터미널 펼치기/접기 | Control + ` |
| 설정 | ⌘, |
| 단축키 목록 | ⌘K를 누른 뒤 ⌘S |
| 문서 편집 실행 취소 | ⌘Z |

⌘는 Command, ⇧는 Shift입니다. 키보드 배열·개인 설정에 따라 다를 수 있습니다.
안 되면 명령 팔레트에서 기능 이름을 찾으세요.
⌘Z가 AI의 모든 외부 행동(메일 삭제·발송 등)을 취소하지는 않습니다.

## 화면이 복잡해졌을 때

왼쪽 아이콘 영역을 우클릭하여 Source Control, Run and Debug, Testing을 숨길 수 있습니다.
Explorer, Search, Codex는 남겨 두세요. View > Appearance에서 다시 표시할 수 있습니다.
AI에게 “파일 목록, 문서, Codex 중심으로 화면을 다시 정리해 줘”라고 말해도 됩니다.
한국어 메뉴와 영어 메뉴가 다르면 아이콘과 명령 팔레트로 찾습니다.

자동 저장은 파일 저장을 돕지만 백업은 아닙니다. 결과를 중요한 외부 문서로 내보낼 때는
다시 열어 내용과 모양을 확인하세요.
