# 컴퓨터 용량과 성능 챙기기

먼저 상태를 읽고, 어떤 파일과 앱이 영향을 주는지 보여 달라고 하세요.
‘컴퓨터 정리’는 모든 캐시·다운로드·메일을 지워도 된다는 뜻이 아닙니다.

```text
내 Mac의 저장 공간과 느려지는 원인을 먼저 확인해 줘.
아직 삭제하거나 앱을 종료하지 말고, 효과가 큰 후보와 복구 방법을 보여 줘.
```

에이전트는 시스템 저장 공간과 활동 모니터에서 디스크·메모리 압력·CPU를 확인합니다.
허용한 Downloads/Desktop/00_inbox부터 큰 파일·중복 후보를 목록으로 만듭니다.
원래 경로, 크기, 수정 날짜, 필요한 이유, 제안 동작을 보여 줍니다.
이름이 같다고 중복으로 확정하지 않고 내용 해시와 용도를 확인합니다.
오래됐다는 이유만으로 계약·사진·세금 증빙·백업을 삭제하지 않습니다.

승인된 후보만 작은 묶음으로 옮기거나 휴지통으로 보냅니다.
원본 경로와 이동 결과를 로컬 작업 기록에 남기고 새 위치에서 열리는지 확인합니다.
정리 전후 실제 사용 가능 용량을 비교합니다. 휴지통으로 옮기기만 했다면
휴지통을 비우기 전까지 용량이 회수되지 않을 수 있음을 설명합니다.

앱 제거·로그인 항목 변경은 현재 쓰는지 확인하고 되돌리는 방법을 기록합니다.
금융 보안 앱·백업 앱·회사 관리 프로그램·공유 서버를 임의로 끄지 않습니다.
OS/앱 업데이트는 저장 중인 작업과 재시작 시간을 확인하고 공식 경로로 진행합니다.
보안 기능 해제·레지스트리식 ‘청소’·메모리 정리 앱 구매를 성능 개선 기본값으로 삼지 않습니다.

00_inbox는 임시 분류함입니다. 주 1회 원하면 정리를 제안할 수 있지만
동의 없는 예약 삭제나 백그라운드 감시는 하지 않습니다.
