# 웹 채팅에서 AI와 함께 일하기로

웹 채팅에서는 질문하고 답을 받았다면, 여기서는 AI가 실제 파일을 읽고 결과를 저장할 수 있습니다.
“이 영수증을 정리해서 표로 저장해 줘”처럼 **자료 + 원하는 결과 + 주의할 점**을 말해 주세요.

| 말 | 쉬운 뜻 |
| --- | --- |
| 에이전트 | 자료를 읽고 도구로 일을 수행하는 AI |
| 세션 | 한 업무를 함께 진행하는 대화방 |
| 모델 | 일을 처리하는 AI 종류. 기본은 Sol |
| medium / low | 추론 수준. 항상 높을수록 좋은 것은 아님 |
| 컨텍스트 | 현재 AI가 읽고 참고하는 자료 |
| 공통기억 | 다음 세션도 읽을 수 있도록 파일로 저장한 선호·결정 |
| MCP / 플러그인 | AI와 메일·브라우저·문서 도구를 연결하는 통로 |
| Full Access | 파일·명령 실행의 넓은 권한. 중요한 행동의 승인과는 별개 |
| 저장소(레포) | 설치 키트의 버전을 보관하는 곳. 업무에는 기본 불필요 |
| Markdown | 제목·체크박스를 간단한 기호로 쓰는 문서 형식 |

## 한 세션에는 한 업무

‘9월 영수증 정리’, ‘여행 일정’, ‘고객 답장 초안’처럼 나누세요.
작업이 끝나면 결과를 저장하고 세션을 종료하는 것이 좋습니다.
같은 업무의 추가 설명은 그 세션에서 이어 가고, 주제가 크게 달라지면 새 세션을 엽니다.
너무 많은 일을 섞으면 중요한 조건을 놓칠 수 있습니다.

## 기억은 어떻게 이어지나요?

다른 세션의 대화가 기본으로 전부 공유되는 것은 아닙니다.
이 환경은 새 세션이 `Memory/MEMORY.md`와 관련 파일을 읽도록 지침을 둡니다.
‘이 선호는 다음에도 적용해 줘’라고 하면 필요한 내용을 저장하고 다시 읽어 확인합니다.
일시적인 말이나 모든 대화를 쌓지 않고 중요한 결정·이유·다음 행동만 남깁니다.
같은 파일을 두 세션에서 동시에 고치는 것은 피하세요.
다른 Mac에는 자료를 옮기거나 별도 동기화를 해야 기억이 이어집니다.

## 챙겨 주는 범위

AI는 세션을 시작하면 오늘 TODO와 미완료를 보고 다음 일을 제안합니다.
세션을 닫았다고 혼자 계속 메일을 보거나 정리하지는 않습니다.
자동 알림은 따로 일정·실행 환경·권한·취소 방법을 설정하고 확인해야 합니다.

AI는 실수할 수 있습니다. 금액·날짜·받는 사람·삭제 목록을 원본과 대조하도록 요청하세요.
원하지 않는 방향이면 “멈춰. 여기까지만 하고 현재 상태를 알려 줘”라고 말하세요.
