# 백업·복구·재설치

## 저장과 백업은 다릅니다

이 책상에는 Git이 없습니다. 자동 저장은 현재 파일을 저장할 뿐 이전 버전을 보장하지 않습니다.
소유자가 Time Machine이나 원하는 백업 위치를 선택하고 실제 파일 하나를 복원해 확인합니다.
클라우드 동기화는 다른 기기에서 쓰기 편하지만 삭제도 동기화될 수 있습니다.
개인·사업 자료의 공유 범위를 확인하고, 설치자가 임의로 iCloud/Drive에 업로드하지 않습니다.

## 실수했을 때

문서 편집 직후에는 ⌘Z가 도움이 될 수 있습니다. 외부 발송·파일 삭제 전체를 되돌리는 버튼은 아닙니다.
즉시 작업을 멈추고 원래 파일·이동 기록·휴지통·백업을 확인합니다.
AI에게 “추가 변경을 멈추고, 무엇이 바뀌었는지와 복구 가능한 방법부터 알려 줘”라고 말하세요.

## 설치를 다시 실행할 때

키트의 setup 스크립트는 기존 파일을 덮어쓰지 않습니다.
`same`은 같음, `conflict`는 보존한 기존 파일과 새 기본값이 다름을 뜻합니다.
먼저 미리보기로 확인하고 해당 파일을 백업한 뒤 필요한 부분만 비교·병합합니다.
개인화한 매뉴얼·Memory·TODO를 템플릿으로 통째로 덮어쓰지 않습니다.
심볼릭 링크를 따라 외부 위치에 쓰려 하면 중단합니다.

프로젝트 설정은 `AI Desk/.codex/config.toml`, 문서 화면 설정은 `.obsidian/`(VS Code 예비는 `.vscode/settings.json`)입니다.
Obsidian을 쓰면 `.obsidian/app.json` 등이 바뀌므로 재실행 시 `conflict`가 정상입니다. 기본값과 비교해 필요한 것만 되돌립니다.
기존 `~/.codex/config.toml`은 자동으로 변경하지 않습니다.
정책이나 기존 프로젝트 설정이 우선하면 설치 에이전트가 원인을 확인하고 새 세션에서 검증합니다.

## 브라우저가 끊겼을 때

Chrome의 평소 창과 확장 상태, relay 실행 여부를 먼저 확인합니다.
재부팅 후에는 manual/07-connections.md의 relay 시작 명령이 필요할 수 있습니다.
같은 승인 팝업을 계속 띄우거나 새 창·별도 프로필로 우회하지 않습니다.
이미 다운로드되거나 실행된 작업인지 먼저 확인하고 재시도합니다.

## 설치 키트를 지워도 되는 시점

AI Desk만 열어 새 세션의 공통기억·TODO·도구가 작동함을 확인한 뒤입니다.
키트에는 실사용 자료를 저장하지 않습니다. 필요하면 설치 담당자가 ZIP을 보관합니다.
삭제할 폴더가 `ai-desk-setup`인지 확인하고 **AI Desk 업무 폴더와 혼동하지 마세요.**

도구를 그만 쓸 때는 연결된 앱 권한을 먼저 철회합니다.
업무 폴더 삭제는 백업과 소유자의 명시적 결정이 필요하며 설치 취소에 자동으로 포함되지 않습니다.
