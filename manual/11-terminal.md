# 터미널은 필요할 때만

터미널은 컴퓨터에 글로 명령하는 창입니다. 평소 업무는 Codex에 한국어로 부탁하면 됩니다.
설치·연결 확인 때만 아래 정도를 알아 두면 충분합니다.

| 입력/단축키 | 하는 일 |
| --- | --- |
| `pwd` | 지금 위치 표시 |
| `ls` | 현재 폴더의 파일 이름 보기 |
| `cd "$HOME/AI Desk"` | 내 업무 폴더로 이동 |
| `open .` | 현재 폴더를 Finder로 열기 |
| `code .` | 현재 폴더를 VS Code로 열기(code 등록 후) |
| `codex` | 현재 폴더에서 Codex 시작(CLI 설치 후) |
| `codex resume` | 이전 대화 선택 |
| ↑ | 이전에 입력한 명령 보기 |
| Tab | 파일·폴더 이름 자동 완성 |
| Control+C | 현재 명령 중단(이미 실행된 변경은 되돌리지 않음) |
| `exit` | 현재 셸 종료 |

공백이 있는 경로는 따옴표로 감쌉니다. `$HOME`은 내 사용자 홈 폴더입니다.
예제의 `>`나 `$` 프롬프트 기호까지 복사하지 마세요.
비밀번호 입력 때 글자가 보이지 않는 것은 정상일 수 있습니다. 암호는 AI 대화에 붙이지 않습니다.
출처 모를 명령은 먼저 “이 명령이 무엇을 바꾸는지 설명해 줘”라고 물어보세요.

Git의 clone/pull은 설치 담당자가 키트를 받을 때 사용하는 명령입니다.
AI Desk에서는 git init·commit·push를 할 필요가 없습니다.
