# Obsidian과 Codex 앱을 업무 책상으로 쓰기

화면은 두 창입니다. **Obsidian**은 문서를 보고 고치는 창, **Codex 앱**은 AI와 대화하는 창입니다.
둘 다 같은 `AI Desk` 폴더를 봅니다. Codex가 파일을 만들거나 고치면 Obsidian에 바로 나타납니다.
왼쪽에 Obsidian, 오른쪽에 Codex 앱을 두면 편합니다.

## 여는 방법

- Obsidian: 앱을 열면 마지막에 쓰던 AI Desk vault가 그대로 열립니다. 처음 한 번은
  “Open folder as vault”로 `AI Desk` 폴더를 선택합니다. vault는 ‘폴더를 문서 책상으로 연 것’이라는 뜻입니다.
- Codex 앱: 앱을 열고 왼쪽 프로젝트 목록에서 `AI Desk`를 고른 뒤 한국어로 말합니다.
  처음 한 번은 폴더를 추가하고 신뢰 확인에 동의합니다.

## Obsidian에서 자주 쓰는 것

| 동작 | 방법 |
| --- | --- |
| 파일 이름으로 열기 | ⌘O |
| 폴더 전체 내용 검색 | ⇧⌘F |
| 지금 문서 안에서 찾기 | ⌘F |
| 왼쪽 파일 목록 숨기기/보기 | 왼쪽 위 사이드바 아이콘 |
| 편집 화면과 읽기 화면 전환 | ⌘E |
| 기능 이름으로 실행(명령 팔레트) | ⌘P |
| 되돌리기 | ⌘Z |
| 설정 | ⌘, |

저장 버튼은 없습니다. 입력하면 바로 저장됩니다.
⌘는 Command, ⇧는 Shift입니다. 안 되면 명령 팔레트에서 기능 이름을 찾으세요.
⌘Z는 문서 편집만 되돌립니다. AI의 외부 행동(메일 삭제·발송 등)을 취소하지는 않습니다.

## 설치 시 맞춰 둔 설정

- 마크다운 기호를 몰라도 되도록 편집 화면에서 바로 모양이 보입니다(Live Preview).
- 새 파일과 첨부는 `00_inbox`에 들어갑니다.
- 문서 사이 링크는 `[제목](파일.md)` 표준 형식입니다. AI가 만든 문서와 같은 형식이라 서로 열립니다.
  Obsidian의 `[[ ]]` 링크는 쓰지 않습니다.
- 그래프·백링크·캔버스 같은 기능은 꺼 두었습니다. 필요하면 설정 > 핵심 플러그인에서 켤 수 있습니다.
- 커뮤니티 플러그인은 켜지 않습니다. 설정은 `.obsidian` 폴더에 있고 Obsidian 목록에는 보이지 않습니다.
- 표시 언어는 설정 > 일반 > 언어에서 한국어를 고릅니다. 이 설정은 vault가 아니라 앱에 저장됩니다.
- 파일 삭제는 확인 후 Mac 휴지통으로 갑니다.

## Codex 앱에서 확인할 것

새 대화를 시작하면 입력창 근처에서 모델과 권한을 확인합니다.
기본은 **GPT-5.6 Sol / medium**, 권한은 **Full Access**입니다.
다르게 보이면 AI에게 “모델과 권한을 기본값으로 맞춰 줘”라고 말하거나 선택기에서 고릅니다.
Codex 앱의 메뉴는 영어일 수 있습니다. 대화는 한국어로 하면 됩니다.

## 화면이 복잡해졌을 때

AI에게 “Obsidian 설정을 처음 설치 상태로 다시 정리해 줘”라고 말하면 됩니다.
`.obsidian` 폴더의 설정 파일을 키트 기본값과 비교해 필요한 것만 되돌립니다.
자동 저장은 백업이 아닙니다. 결과를 중요한 외부 문서로 내보낼 때는 다시 열어 내용과 모양을 확인하세요.

## VS Code를 대신 쓰는 경우

Codex 앱을 설치할 수 없는 Mac에서는 VS Code + Codex 확장으로 같은 폴더를 엽니다.
설치 시 만든 `.vscode/settings.json`이 줄 번호·미니맵을 줄이고 자동 저장을 켭니다.
VS Code는 개발 도구라 화면 요소가 많습니다. 왼쪽 아이콘 영역 우클릭으로
Source Control, Run and Debug, Testing을 숨기고 Explorer, Search, Codex만 남기세요.

[Obsidian 도움말](https://help.obsidian.md/),
[Codex 앱 안내](https://learn.chatgpt.com/docs/app),
[VS Code 설정](https://code.visualstudio.com/docs/configure/settings).
