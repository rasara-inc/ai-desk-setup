# 오늘 할 일과 공통기억

## 아침

```text
공통기억과 오늘 TODO, 반복 일정을 읽어 줘.
오늘 꼭 해야 할 일부터 세 개만 골라서 이유와 첫 행동을 알려 줘.
```

파일은 `00_TODO/2026-09-14-Mon.md`처럼 날짜와 요일로 만듭니다.
오늘 날짜는 거주 지역 시간대 기준입니다. 내용은 한국어로 씁니다.

```markdown
# 2026-09-14 Mon

## 오늘 할 일

- [ ] 거래처 메일에서 답장이 필요한 건 확인하기
- [ ] 이번 주 영수증 5장 정리하기
```

여러 날 걸리는 업무는 `projects.md`나 해당 업무 폴더에 상태를 둡니다.
날짜별 파일에는 오늘 할 행동만 적습니다. 정기 업무는 `recurring.md`에 다음 예정일을 둡니다.

## 마감

```text
오늘 한 일을 확인하고 마감해 줘.
미완료는 적절한 다음 날짜로 옮기고, 이어갈 업무와 중요한 결정만 저장해 줘.
```

완료한 일은 `[x]`로 남깁니다. 옮긴 일은 원래 날짜에서 없애고 다음 날짜에 적습니다.
‘이월’ 표시나 이동 안내를 남기지 않습니다. 날짜 파일 보관함 이동은 요청할 때 합니다.
완료하지 않은 일을 완료했다고 표시하지 않습니다.

## 기억

Memory에는 다음에도 필요한 호칭·선호·중요한 결정과 이유를 남깁니다.
개별 증빙·긴 작업 기록은 해당 업무 폴더에 두고 링크만 연결합니다.
새 정보가 없으면 기억 파일을 새로 만들 필요가 없습니다.
비밀번호와 인증코드는 기억에 넣지 않습니다.

새 세션에서 “공통기억을 읽고 어제 이어갈 일의 다음 행동을 알려 줘”라고 확인해 보세요.
자동으로 채팅 전체를 기억하는 기능과 이 책상의 파일 기반 기억은 다릅니다.
