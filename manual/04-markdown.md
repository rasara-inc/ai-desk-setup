# Markdown 직접 써 보기

확장자가 `.md`인 파일은 글과 간단한 기호로 작성합니다.
아래를 `00_inbox/practice.md`에 붙여 넣고 ⇧⌘V로 미리 보세요.

```markdown
# 이번 주 준비

## 오늘 할 일

- [ ] 거래처 메일 확인
- [ ] 영수증 정리
- [x] 회의 시간 확인

**중요:** 금액은 CAD 기준입니다.

1. 원본을 확인한다.
2. 표로 정리한다.
3. 다시 대조한다.

| 날짜 | 항목 | 금액(CAD) |
| --- | --- | ---: |
| 2026-09-14 | 사무용품 | 25.00 |

[사용 설명서](../manual/README.md)

> 아직 확정되지 않은 내용은 따로 표시합니다.
```

`#`는 큰 제목, `##`는 작은 제목, `-`는 목록입니다.
`[ ]`를 `[x]`로 바꾸면 완료 표시가 됩니다. 별 두 개로 감싸면 굵은 글씨입니다.
빈 줄로 문단을 나누세요. 링크는 `[표시할 글](경로 또는 주소)`입니다.

사진은 `![설명](photo.jpg)`로 넣을 수 있습니다. 실제 파일이 같은 폴더에 있어야 보입니다.
AI에게 “이 메모를 읽기 쉬운 Markdown으로 정리해 줘”라고 부탁해도 됩니다.
표의 예시 금액은 실제 지출이 아닙니다.
