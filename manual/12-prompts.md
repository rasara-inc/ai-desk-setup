# 계속 함께 일하는 요청 예시

## 하루 시작

```text
오늘 일정과 TODO를 보고 내가 놓친 것이 있는지 챙겨 줘.
가장 중요한 일 세 개와 지금 10분 안에 할 행동 하나를 알려 줘.
```

## 이메일

```text
답장이 필요한 중요 메일을 먼저 찾아 줘.
광고는 구독 해지 후보를 정리하고, 삭제할 목록과 예외를 보여 준 다음 내 확인을 받아 줘.
```

## 영수증

```text
00_inbox의 영수증을 날짜·판매처·소계·세금·총액·통화로 정리해 줘.
읽기 어려운 값은 추측하지 말고 표시해 줘. 원본과 표를 다시 대조해 줘.
```

## 사업/직장

```text
이 거래처 메일을 읽고 내가 해야 할 일과 기한을 정리해 줘.
답장은 영어 초안으로 만들어도 되지만 나에게 설명할 때는 한국어로 해 줘. 보내지는 마.
```

## 컴퓨터 정리

```text
Downloads에서 용량을 많이 쓰는 파일을 찾아 정리 후보를 보여 줘.
중요한 자료와 백업은 보존하고, 무엇을 옮기거나 삭제할지 확인받아 줘.
```

## 막혔을 때 / 종료

```text
내가 개발자가 아니라고 생각하고, 지금 내가 눌러야 할 것 하나만 알려 줘.
```

```text
이 업무를 마무리해 줘. 결과 파일을 저장하고 다시 열어 확인한 뒤,
다음 세션에도 필요한 결정과 이어갈 일만 공통기억에 남겨 줘.
```

한국어 대화 원칙은 외부 수신자용 영어 초안을 못 만든다는 뜻은 아닙니다.
AI는 외부 문안을 요청한 언어로 만들고 설명·확인은 한국어로 합니다.
