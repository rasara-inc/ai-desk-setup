# Browser helper

설치 후 `AI Desk/.tools/browser/browser.mjs`를 실행합니다.
Node.js 22+, Playwriter 0.5.0 relay(127.0.0.1:19988), 호환 Chrome 확장이 필요합니다.
이 폴더는 키트 없이도 독립적으로 작동합니다. `tasks/`에는 자기 작업의 UUID와 탭 소유권만 저장합니다.
소유권을 확인할 수 없으면 조작을 거부합니다. 새 창과 직접 디버깅 연결은 지원하지 않습니다.

사용법과 연결/재부팅 후 재개 방법은 설치된 `manual/07-connections.md`를 읽으세요.
스크린샷은 기존 파일을 덮어쓰지 않습니다. 새 파일명을 지정하세요.
프로토콜 호환성과 로그인·권한은 현장 테스트가 필요합니다.
