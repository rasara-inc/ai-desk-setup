# 설치·연결 현황

| 항목 | 상태 | 확인 근거 / 다음 행동 |
| --- | --- | --- |
| 폴더·설정 | 미검증 | doctor 실행 |
| VS Code 화면 | 미검증 | 소유자가 다시 열어 확인 |
| 소유자 로그인·Pro 5x | 미검증 | 로그인·구독 화면 확인 |
| Sol medium + Full Access | 미검증 | 새 세션 선택기 확인 |
| 공통기억·날짜 TODO | 미검증 | 새 세션에서 재현 |
| Chrome 그룹 도구 | 미검증 | 자기 그룹 실습 |
| Computer Use | 미검증 | OS 권한과 비파괴 실습 |
| 문서·PDF·표 도구 | 미검증 | 기능별 설치와 결과 파일 확인 |
| 이메일 | 미검증 | 선택 계정 읽기와 승인 범위 |
